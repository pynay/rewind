## Decision

Created a single fetch wrapper (omnaraFetch) that adds Bearer auth and base URL, logs all requests/responses. Exports 5 typed functions: getSessionDetail, getAgentSessionMessages, importClaudeSession, launchWorkspaceSession, createUserSession. Config reads from env at call time (not module load) so missing tokens fail at request time, not import time. All types derived from Omnara API docs (unstable — may need adjustment). Key finding: launch endpoint uses `initial_prompt` not `initial_message` as originally spec'd in CLAUDE.md.

## Assumptions

- Omnara API response shapes match docs as of 2026-04-12
- payload.content from GET messages has compatible shape with import content field

## Risk

API is marked unstable — response shapes may change without notice
