## Decision

Maps sender.kind to role (user->user, agent_session->assistant), filters out system messages, passes payload.content through as-is (assuming shape compatibility). Merges metadata from both msg.metadata and payload.metadata with msg.metadata taking priority. This is a passthrough approach — we'll adjust once we see real response shapes and know if content needs restructuring.

## Assumptions

- payload.content shape from GET messages matches ImportMessageContent shape expected by import endpoint
- system messages should be dropped rather than mapped
