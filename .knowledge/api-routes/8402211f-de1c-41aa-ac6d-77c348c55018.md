## Decision

Thin proxy route that forwards paginated message requests to the Omnara API via getAgentSessionMessages. Params are awaited (Next.js 15 async params). Query params: limit (clamped 1–200, default 50), before_id, after_id — only included in the call when actually provided. Returns Omnara response as-is (messages, has_more, next_cursor). Error handler extracts Error.message or falls back to generic string. No response validation or caching in v1.

## Alternatives

- Could add Zod response validation for type safety at runtime
- Could add in-memory caching to reduce Omnara API calls

## Assumptions

- Omnara API response shape matches MessagesResponse type
- No auth needed beyond server-side OMNARA_API_TOKEN
